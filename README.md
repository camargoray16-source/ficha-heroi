# 📙 Portfólio Pessoal - Front-End

Este é o meu projeto desenvolvido para a disciplina de **Tecnologia Web**. Trata-se de uma ficha/portfólio temática do herói Eliseu, apresentando suas informações, atributos, inventário, conquistas e formas de contato.

---

## 📌 Sobre o Projeto

Este site foi criado com o foco em aplicar os conhecimentos práticos de **HTML5**, **CSS3**, **Flexbox**, **CSS Grid** e boas práticas de estruturação visual.

O projeto foi organizado para apresentar:
- **Sobre o Herói:** Informações da história e imagem principal.
- **Atributos & Habilidades:** Barras de progresso e lista de habilidades com ícones.
- **Inventário:** Exibição dos itens em grade com raridade e descrição.
- **Status & Conquistas:** Métricas detalhadas do personagem.
- **Contato com a Guilda:** Links úteis para interação.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização, Flexbox, CSS Grid e responsividade)
- **Google Fonts** (Fontes *Cinzel* e *Poppins*)
- **Font Awesome** (Ícones da interface)
- **Git & GitHub** (Controle de versão e hospedagem)
